# UNICAMP 2028 — Study Tracker

> Plataforma pessoal de organização e acompanhamento dos estudos para o processo de ingresso na Universidade Estadual de Campinas (UNICAMP) em 2028.

## Sobre o projeto

O **UNICAMP 2028 — Study Tracker** é uma aplicação web desenvolvida por uma inteligência artificial para organizar, acompanhar e visualizar minha preparação para o processo seletivo da UNICAMP.

O projeto transforma um conteúdo extenso de preparação em um sistema de acompanhamento, permitindo dividir os estudos por disciplinas, conteúdos e níveis de dificuldade, além de acompanhar o progresso ao longo do tempo.

A proposta é simples:

**Transformar uma preparação de longo prazo em objetivos concretos e mensuráveis.**

## Funcionalidades

- [x] Checklist de conteúdos
- [x] Organização por disciplinas
- [x] Classificação por nível de dificuldade
- [x] Estimativa de tempo de estudo
- [x] Lista de leituras recomendadas
- [x] Barra de progresso
- [x] Contador de conteúdos concluídos
- [x] Salvamento do progresso no navegador
- [x] Interface responsiva
- [x] Organização dos conteúdos para preparação de longo prazo

## Disciplinas

O planejamento contempla diferentes áreas cobradas ao longo da preparação:

- Matemática
- Física
- Química
- Biologia
- História
- Geografia
- Filosofia
- Sociologia
- Língua Portuguesa
- Literatura
- Língua Inglesa
- Redação
- Conteúdos específicos e complementares

Cada disciplina é dividida em tópicos progressivos, permitindo acompanhar desde os fundamentos até conteúdos de maior complexidade.
